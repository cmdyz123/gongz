# 平台导航网站

一个基于Vue 3的平台导航网站，支持登录注册功能，并能记录用户访问各平台的次数。

## 功能特点

- 📱 **平台导航**：提供视频和漫画平台的快速访问链接
- 🔐 **用户系统**：支持注册、登录和登出功能
- 📊 **访问统计**：记录用户访问各平台的次数和时间
- 📱 **响应式设计**：适配不同屏幕尺寸

## 技术栈

- **Vue 3**：前端框架
- **Vue Router**：路由管理
- **Pinia**：状态管理
- **Vite**：构建工具

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产版本

```bash
npm run preview
```

## 使用说明

1. **注册账号**：点击登录页面的"立即注册"链接，填写用户名和密码
2. **登录系统**：使用注册的账号登录
3. **访问平台**：在主页面点击各个平台的卡片，系统会自动记录访问次数
4. **查看记录**：在主页面底部可以查看所有的访问记录
5. **退出登录**：点击右上角的"登出"按钮退出系统

## 项目结构

```
src/
├── assets/          # 静态资源
├── components/      # 组件
│   ├── Login.vue    # 登录组件
│   ├── Register.vue # 注册组件
│   └── Home.vue     # 主页面组件
├── router/          # 路由配置
├── stores/          # 状态管理
├── App.vue          # 根组件
├── main.js          # 入口文件
└── style.css        # 全局样式
```

## 自定义配置

### 添加新平台

在`Home.vue`组件中，找到`videoPlatforms`或`comicPlatforms`数组，添加新的平台对象：

```javascript
{
  name: '平台名称',
  url: '平台链接',
  icon: '平台图标'
}
```

## 注意事项

- 本项目使用本地存储（localStorage）保存用户信息和访问记录，数据仅保存在浏览器中
- 实际项目中应该使用后端API进行用户认证和数据存储
